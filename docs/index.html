Run it yourself

The whole protocol is nine typed tools defined once in flyway-core and exposed through an agent skill, an MCP server, and a CLI. From a clean clone:

# two independent murmurations, mutual recognition, a signed tension
git clone https://github.com/murmurations-ai/flyway && cd flyway
pnpm install && pnpm --filter '!*harness' -r build
node packages/cli/dist/bin/flyway.js init --repo-url https://github.com/you/repo --source-name "You"
