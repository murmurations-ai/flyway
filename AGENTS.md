# AGENTS.md — flyway for agents

You are an agent operating for a **Source** (your human principal). This repo is **flyway**: a runtime-agnostic protocol that lets your murmuration collaborate with *other* independent murmurations — discover them, verify identity cryptographically, exchange governance signals, co-sign agreements, and exit cleanly — with **no central controller**.

## Learn the protocol (read these, in order)

1. **[`packages/core/src`](./packages/core/src)** — the nine tools defined once as JSON Schema, plus the protocol instructions every adapter serves. This is the authoritative spec.
2. **The skill** — the [Agent Skills IO](https://agentskills.io) `SKILL.md` generated by [`packages/agent`](./packages/agent): a self-contained protocol primer written for you.
3. **[`docs/architecture/how-flyway-works.md`](./docs/architecture/how-flyway-works.md)** — sequence diagrams, state machines, the signed-envelope contract.
4. **[`docs/walkthroughs/`](./docs/walkthroughs/)** — eight executable end-to-end examples.

## Use the protocol (pick one)

```bash
# Set up once: install deps, build, and put `flyway` + `flyway-mcp` on your PATH
pnpm setup

# A) Install the skill into your agent environment (Claude Code, Cursor, Codex, Gemini CLI, Goose, …)
flyway skill install
flyway skill list

# B) Or run the MCP server (stdio) and register it with your MCP client
flyway-mcp

# C) Or call the CLI directly (use --json where available so you can parse results)
flyway init --repo-url https://github.com/<source>/<repo> --source-name "<Source>"
flyway status --json
```

> Not linking a global command? Run `pnpm install && pnpm build`, then prefix any command with `pnpm` — e.g. `pnpm flyway status --json`, `pnpm flyway-mcp`.

## The nine tools

`flyway_init` · `flyway_status` · `flyway_discover` · `flyway_recognize` · `flyway_tension` · `flyway_propose` · `flyway_respond` · `flyway_check` · `flyway_exit`
(plus `flyway materialize` to co-sign an accepted agreement).

## Rules of engagement

- **Act only under your Source's authority.** Recognition, agreements, and exits are your Source's commitments — surface them, don't invent them.
- **Verify before you trust.** Every incoming signal is signed; `flyway_check` verifies signatures against the recognition-time cached key. Do not act on an unverified or flagged signal.
- **Consent, not control.** flyway never forces agreement. Objections are first-class; exit is the clean end of a process, never a workaround.
- **Git is the record.** Never overwrite another Source's state; you cache and propose, they decide.
